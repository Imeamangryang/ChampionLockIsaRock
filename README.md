# ChampionLockIsaRock

ChampionLockIsaRock는 Unreal Engine 5.7 기반으로 제작된 TFT 스타일 전략 게임의 핵심 루프를 모티브로 구현 프로젝트입니다.  
상점, 벤치/보드 배치, 전투 라운드, 시너지, 합체, 아이템 장착 등 오토배틀러 장르의 핵심 시스템 구현에 중점을 두었습니다.

## 프로젝트 정보

- **장르** : Strategy / Simulation
- **플랫폼** : PC
- **개발 기간** : 2026/03/10 ~ 2026/04/10 (26일)
- **참여 인원** : 3명

## 결과물 링크

- **플레이 영상 / 빌드 링크** : 추후 추가

## 개발 환경

- **Unreal Engine 5.7**
- Windows 11

# 핵심 시스템

## 1. 상점(Shop) 시스템

### 주요 기능
- 플레이어 레벨 기반 리롤 확률 적용
- 5개의 상점 슬롯 표시
- DataTable에서 챔피언 데이터 로딩
- 챔피언 이름 / 오리진 / 클래스 / 코스트 / 이미지 표시
- 슬롯 클릭 시 골드 차감 후 유닛 구매
- 구매한 유닛을 벤치에 스폰

### 구현 방식
- `TFTShop`  
  순수 C++ 기반으로 골드, XP, 레벨, 리롤, 슬롯 로직을 담당합니다.
- `TFTShopWidget`  
  UMG 위젯으로 실제 UI 표시와 DataTable 기반 랜덤 챔피언 선택을 수행합니다.
- `TFTPieceSlotWidget`  
  개별 챔피언 슬롯 UI이며, 클릭 시 구매 처리 및 유닛 스폰 연결을 담당합니다.


## 2. 벤치(Bench) 시스템

### 주요 기능
- 기본 **9칸 벤치 슬롯** 제공
- Instanced Static Mesh 기반으로 벤치 타일 생성
- 가장 왼쪽 빈 슬롯 탐색
- 슬롯별 유닛 등록 / 해제
- 슬롯 중앙 좌표 반환
- 마우스 위치 기반 가장 가까운 벤치 칸 스냅
- 벤치 표시/숨김 제어

### 특징
- `BenchUnits` 배열로 현재 벤치 유닛 상태를 관리합니다.
- 유닛 구매 시 빈 슬롯에 자동 배치됩니다.
- 드래그 시 벤치 위치로 스냅되며, 전투 중에도 벤치 쪽 조작은 일부 허용됩니다.


## 3. 전투(Grid) 시스템

### 주요 기능
- **헥사곤 형태의 필드 타일 생성**
- 행/열 기반 육각형 배치 계산
- Instanced Static Mesh 기반 보드 렌더링
- 마우스 위치 기준 가장 가까운 전장 타일 스냅
- 필드에 올라간 유닛 목록 관리
- 현재 배치된 유닛 수 계산
- 전장 표시/숨김 제어

### 특징
- `Rows`, `Columns`, `HexSize`, `TileGap` 설정으로 그리드 형태를 조정할 수 있습니다.
- 실제 필드에 올라간 유닛은 `DeployedUnits` 배열로 관리됩니다.
- 전투 시작 시 현재 필드 유닛 목록을 기준으로 출전 명단을 구성합니다.


## 4. 유닛 드래그 앤 드롭 / 배치 시스템

### 주요 기능
- 유닛 클릭 및 집기
- 유닛 드래그 중 마우스 추적
- 벤치/필드 위치 하이라이트 표시
- 필드 ↔ 벤치 이동
- 유닛 간 스왑
- 필드 인원 제한 체크
- 유닛 판매 구역 처리
- 유닛 스폰
- 시너지 재계산 호출
- 전투 중 보드 잠금 상태 반영
- 아이템 드래그 앤 드롭 처리

### 상세 동작
- 좌클릭으로 유닛을 집고 놓을 수 있습니다.
- 유닛을 이동할 때 벤치와 그리드 중 더 가까운 위치로 스냅합니다.
- 벤치에서 필드로 이동할 때는 **현재 플레이어 레벨보다 필드 유닛 수가 많아질 수 없도록 제한**됩니다.
- 다른 유닛이 있는 위치에 놓으면 **스왑**이 발생합니다.
- 특정 태그(`SellArea`)가 있는 영역에 드롭하면 유닛을 판매합니다.
- 이동 완료 후 시너지가 즉시 갱신됩니다.

## 5. 플레이어 골드 / 레벨 시스템

### 관리 데이터
- `PlayerGold`
- `PlayerLevel`
- `CurrentXP`
- `MaxXP`

### 주요 기능
- 골드 획득
- 골드 소비
- 경험치 획득
- 레벨업
- XP 구매
- 스테이지 종료 보상 XP 지급
- UI 서브시스템 이벤트 방송

### 특징
- 스테이지 승리 시 자동 경험치와 골드를 보상으로 획득합니다.
- 값이 변경되면 `UTFT_UISubsystem`을 통해 UI에 즉시 반영됩니다.


## 6. 스테이지 / 전투 진행 시스템

### 주요 기능
- 스테이지 데이터 보관
- 적 유닛 스폰
- 전투 시작
- 전투 종료
- 승패 판정
- 연장전(오버타임) 처리
- 다음 라운드 정산
- 보상 지급
- 보드 잠금 상태 제공
- 준비 단계 시작 이벤트 브로드캐스트

### 연장전 시스템
- 전투 시작 후 **30초**가 지나면 연장전에 돌입합니다.
- 연장전에서는 `GlobalTimeDilation = 2.0f`가 적용되어 게임 속도가 2배가 됩니다.

### 보드 잠금
전투 중이거나 정산 중 상태에서는 필드 배치가 제한됩니다.


## 7. 유닛 합체(업그레이드) 시스템

### 주요 기능
- 같은 챔피언 / 같은 성급 유닛 3개 탐색
- 메인 유닛 선택
- 재료 유닛 2개를 메인 유닛으로 이동시키는 합체 연출
- 재료 유닛 제거
- 성급 상승
- 크기 확대
- 연쇄 합체 재검사
- 이펙트 호출

### 특징
- 우선순위는 **필드 유닛 우선**, 없으면 **벤치의 왼쪽 유닛 우선**입니다.
- 전투 중 메인 유닛이 필드에 있으면 합체를 즉시 실행하지 않고 **보류 목록(PendingUpgradeKeys)** 에 저장했다가 준비 단계에서 처리합니다.
- 2성 3개가 다시 모이면 연쇄적으로 3성 합체도 가능합니다.


## 8. 시너지 시스템

### 주요 기능
- 필드 유닛 목록 수집
- 중복 챔피언 제외
- 챔피언의 Origins / Classes 파싱
- 시너지별 인원 수 계산
- UI 이벤트 브로드캐스트

### 특징
- 벤치 유닛은 제외됩니다.
- 적 유닛은 제외됩니다.
- 동일 챔피언 중복 카운트를 막기 위해 `TSet`를 사용합니다.


## 9. 유닛 캐릭터 시스템

### 주요 역할
- 챔피언 데이터 초기화
- DataTable 기반 스탯/스킬 정보 반영
- 스켈레탈 메시 및 애니메이션 자동 로딩
- HP 바 위젯 연결
- 전투/스탯/스킬 컴포넌트 보유
- 아이템 슬롯 관리
- 아이템 장착 처리
- 공격 / 사망 / 스킬 / 댄스 몽타주 재생

### 포함된 주요 컴포넌트
- `UTFT_StatComponent`
- `UTFT_SkillComponent`
- `UTFT_CombatComponent`
- `UWidgetComponent` (HP/MP UI)

### 특징
- `ChampionKey`와 `starLevel`을 기준으로 유닛을 초기화합니다.
- `InitWithChampionKey()` 호출 시:
  1. `GameInstance`에서 챔피언 DataTable 로드
  2. 해당 챔피언 row 조회
  3. 스탯 및 스킬 초기화
  4. 메시/애니메이션 블루프린트/몽타주 세팅
  5. HP 바 위젯 연결

**공통 유닛 클래스 + 데이터 기반 초기화 구조**를 따릅니다.


## 10. 데이터 기반 챔피언 구조

챔피언 정보는 `FTFT_ChampionData` 구조체를 기반으로 DataTable에서 관리됩니다.

### 챔피언 데이터에 포함되는 정보
- Key
- Name
- Cost
- Portrait/Image
- Origins
- Classes
- AttackDamage
- AbilityPower
- AttackRange
- AttackSpeed
- CriticalChance
- DPS
- Health
- Armor
- MagicResist
- StartingMana
- MaxMana
- SkillName
- SkillType
- SkillDescription
- SkillStats
- SkillImage

### 의미
챔피언 추가/수정이 코드 변경 없이 **DataTable 수정만으로 가능**하도록 설계되어 있습니다.  
상점, 유닛 초기화, 시너지 계산, 스킬 설명 UI 등이 모두 이 데이터를 기반으로 동작합니다.


## 11. 유닛 비주얼 및 애니메이션 로딩

### 자동 로딩 대상
- Skeletal Mesh

- Attack Montage
- Death Montage
- Dance Montage
- Skill Montage

### 특징
이 방식은 **에셋 네이밍 규칙 + 데이터 기반 유닛 초기화**를 결합한 구조입니다.

장점:
- 챔피언 추가 시 코드 중복 감소
- 데이터와 에셋 규칙 기반 확장 가능
- 캐릭터 표현 구조가 일관됨

## 13. 아이템 시스템

### 유닛 장착 구조
- 각 유닛은 기본적으로 **3칸 아이템 슬롯**을 가집니다.
- 빈 슬롯이 있으면 아이템을 장착할 수 있습니다.
- 장착 성공 시:
  1. 슬롯에 아이템 인스턴스 저장
  2. 아이템 정의에서 스탯 보너스 조회
  3. Modifier 배열 생성
  4. `StatComponent`에 적용
  5. HP/MP/UI 갱신
 

## 14. Modifier 기반 스탯 확장

아이템 효과를 단순 수치 덮어쓰기가 아니라 **Modifier 기반 구조**로 처리합니다.

### 장점
- 아이템 / 버프 / 디버프를 같은 방식으로 확장 가능
- 원본 스탯과 최종 스탯 분리 가능
- 일시 효과 및 조건부 효과 확장에 유리
- 유지보수성과 확장성 향상

## 15. UI Subsystem 아키텍처

### 역할
- 유닛 스탯 UI 열기/닫기
- HP/MP 수치 변경 방송
- 인벤토리 UI 갱신
- 골드 UI 갱신
- 레벨/XP UI 갱신

### 의미
게임 로직 클래스들이 위젯을 직접 조작하지 않고, **Subsystem을 통해 이벤트를 브로드캐스트하고 UI가 이를 구독**하는 구조를 사용합니다.

장점:
- 로직과 UI 결합도 감소
- 유지보수 용이
- HUD / 인벤토리 / 전투 UI 확장에 유리

# 프로젝트 의의

ChampionLockIsaRock는 Unreal Engine 5.7 환경에서 TFT 스타일 오토배틀러의 핵심 시스템을 직접 구현해본 프로젝트입니다.  
단순 UI 재현을 넘어서, 상점-배치-전투-정산으로 이어지는 게임 루프를 실제 플레이 가능한 구조로 연결하는 데 초점을 두었습니다.

특히 다음과 같은 점에서 의미가 있습니다.

- DataTable 기반으로 챔피언/아이템 데이터를 분리하여 확장성을 확보
- 벤치와 헥스 그리드 배치 시스템을 통해 전략 게임의 공간 구조 구현
- 드래그 앤 드롭, 시너지 계산, 합체, 아이템 장착 등 TFT 핵심 규칙을 C++ 중심으로 설계
- UI Subsystem과 GameFramework를 활용해 로직과 UI를 분리하는 구조 적용

## 개선 방향

현재 프로젝트는 TFT의 핵심 루프를 구현하는 데 집중했으며, 향후 다음과 같은 방향으로 확장할 수 있습니다.

- 아이템 조합 및 특수 효과 시스템 추가
- 전투 AI 및 타겟 선정 로직 고도화
- HUD 및 전투 UI 개선
- 멀티플레이로의 확장


## 마무리

ChampionLockIsaRock는 Unreal Engine 기반에서 오토배틀러 장르의 핵심 시스템을 구조적으로 구현해본 프로젝트이며, 게임플레이 로직 설계와 데이터 중심 구조 설계 경험을 함께 담은 결과물입니다.
